# Fonts

The design uses Strategie's typeface, **Helvetica Neue LT Std** (400 / 500 / 700).
It is a licensed font, so it is not included here. Get the web files from the
client and drop them in this folder with these names:

- `HelveticaNeueLTStd-Roman.woff2` (400)
- `HelveticaNeueLTStd-Md.woff2` (500)
- `HelveticaNeueLTStd-Bd.woff2` (700)

Until then the page falls back to a locally installed Helvetica Neue, then
Helvetica, then Arial (on Windows that means Arial).
